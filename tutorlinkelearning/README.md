### To get the App Running

First make sure you have flutter SDK installed
Secondly run flutter doctor in your terminal and add every other thing that is unmarked in the terminal
Thirdly Get and Emulator(recommend using android studios to get it )
Now, in the App's root directory, run "flutter pub get" to get all the required dependencies for the app and make sure you have an internet access.
Lastly run "flutter run" to get the app running and make sure to start the emulator first before this else the SDK will identify the available device to run or debug app mostly chrome or edge
